📖 Hướng dẫn sử dụng

4 bước để phát sóng TikTok LIVE với sàn nhảy 3D.

1

🖥️ Khởi động game

Mở TikTokLiveBar.exe (hoặc Play trong Unity). Chờ hiện NODE ONLINE.

2

📱 Kết nối TikFinity

Mở TikFinity Desktop → đăng nhập → bật LIVE. Tab 🔴 Live → nhập username → Kết nối.

3

📺 Thêm vào OBS

Game Capture cửa sổ game. Trong game bấm F2 để bật Chroma Key nền xanh.

4

🎮 Test thử

Tab 🧪 Test Lab → 30 người. Tab 🎯 Events để bắn gift thủ công.
